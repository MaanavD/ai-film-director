# AI film director skill

An agent skill for planning and making a short AI film with the creator involved in the decisions. It covers the story, visual references, starting frames, motion prompts, clip review, editing, and audio.

The workflow builds on [Eian's AI film guide](https://x.com/EianLu/status/2118317430665613741) and the lessons from trying it on a series of short films. It favors shots with natural cuts when continuity is difficult, while leaving the creative choice to you.

## Use

Copy `skills/ai-film-director` into your agent's skills directory, then ask the agent to use `ai-film-director` to help make a film. Tell it what tools and models you have access to. The skill describes a workflow; it does not bundle a video model or generation service.

Review the style, frames, clips, and final edit yourself. Generating media may require paid services and a budget.
